# DIY 思维导图｜本轮视觉与交互设计

负责人：黄崇杰。日期：2026-11-23。方向为“克制层级”：保持暖白画布与蓝紫强调，不引入分支配色，用层级、路径和留白建立秩序。

## 设计目标

1. 画布是主角：标题、状态、工具与底部操作尽量压缩，画布获得最多可用高度。
2. 先看结构再看文字：根节点、一级分支、叶子的权重依次降低；选中时整条分支可追踪。
3. 状态一眼可辨：选中、折叠、候选、生成中、错误、空图各有明确反馈，不依赖说明文字。
4. 与现有四页一致：沿用 `fs_bg / fs_surface / fs_text / fs_muted / fs_border / fs_accent / fs_soft / fs_danger`，跟随系统深浅色。

## 画布

| 元素 | 设计 |
| --- | --- |
| 根节点 | 蓝紫实心圆角矩形，`fs_on_accent` 文字，粗体 15vp |
| 一级节点 | 白/深色面板底，1.2vp 蓝紫描边，15vp 普通字重 |
| 叶子节点 | 面板底，1vp `fs_border` 细边 |
| 选中节点 | `fs_soft` 填充 + 2.5vp 蓝紫描边；根节点选中时改用 `fs_on_accent` 描边 |
| 选中分支 | 从根到选中节点的连线全部改为蓝紫 2.6vp；路径上的中间节点 1.8vp 蓝紫描边 |
| 普通连线 | `fs_connector` 1.8vp，弱于分支高亮 |
| 折叠徽标 | 节点右缘 22vp 蓝紫圆点；展开为 `−`，折叠为 `+N`（N 为隐藏后代数，超过 99 显示 `+99`） |
| 点阵背景 | 24vp 间距，随平移/缩放移动；只作为空间参照，不抢节点对比 |
| 字号 | 15vp，中文 HarmonyOS Sans，行高 22；节点宽度按中文字符近似宽度换行，最多 10 个字符一行 |

颜色全部经 `ColorMetrics` / `resourceManager` 解析，深色模式使用同一语义色板；不写死白色文字。

## 2D 与 3D 两种画布

右下角缩放条最左侧是 `2D / 3D` 切换按钮，当前模式以浅紫底标出；切换后自动适应画布，不改变文档数据和撤销历史。

**2D（默认）**：平面树布局，节点与连线保持固定间距，适合精确编辑和大量节点阅读。

**3D（球形轨迹球旋转）**：
- 节点中心先按 `(x, y, depth*70)` 放到三维空间，再乘一个 3×3 朝向矩阵，最后做透视除法 `distance / (distance + z)`。默认朝向由 yaw −20°、pitch 20° 的矩阵给出，相机距离随场景尺寸增大。
- 拖动不是简单的 yaw/pitch 角度累加，而是轨迹球：以拖动方向在相机空间构造旋转轴，按拖动距离构造增量旋转矩阵，再乘到起始朝向上。任意方向拖动都能连续旋转，没有俯仰上限，也没有欧拉角的万向锁死点。
- 投影前按层级把树稍微展开（`fan = 1 + min(0.5, depth*0.15)`），避免旋转后父子卡片挤在同一屏幕区域；这不是缩放卡片，只展开节点位置。
- 卡片保持正面朝向（billboard），按投影比例缩放；仍绘制“投影阴影 + 右下厚度面 + 顶面”。浅色模式厚度面取顶面颜色的 62% 明度；深色模式非根卡片提亮到 1.4 倍，根节点仍用 72% 暗面。
- 绘制顺序按相机空间深度从远到近；选中卡片最后补绘顶面，避免被近处卡片遮住，也不把阴影抹到邻近卡片上。
- 交互：3D 下单指拖动像转球一样自由旋转；双指拖动平移；双指捏合缩放；右下角“复位”恢复默认朝向并适应画布。2D 下单指仍为平移。
- 连线、徽标和选中路径都使用投影后的坐标；命中测试使用投影卡片矩形和徽标圆点。
- 3D 是阅读/展示视图，不改变领域数据；导出 PNG/Markdown/JSON 始终使用完整 2D 树布局，与当前视角无关。

对照预览：[2D / 3D 设计预览](../design/README.md)（浏览器复刻，非原生截图）。

## 页面结构

```text
标题 / 保存状态 / 撤销 / 重做 / 导出
候选或生成状态条（有状态时才出现）
画布（最大弹性空间）
  ├─ 空图提示（仅一个根节点时）
  └─ 右下角缩放 / 百分比 / 适应
底部单行：当前分支名 + 编辑 + 添加 + 更多 + 继续整理
```

- 顶部内边距由 10vp 收到 7vp，底部由两行收为一行，画布约多出 20–30vp。
- 低频操作（同级节点、折叠、移动、删除、布局、重命名、原文）留在“更多导图工具”面板。
- 底部常用触控目标保持至少 44vp；“继续整理”为 40vp 高的胶囊按钮，仍满足可点区域。
- 候选面板：标题 + 节点数、修改范围、摘要、一次撤销提示；“确认应用”宽度为主按钮的 1.8 倍，“放弃候选”为次要按钮。
- 对话面板：顶部用浅紫卡片显示“修改范围”，非根节点提供“改为整图”；输入框与发送按钮固定在面板底部，键盘弹出使用 `TRANSLATE_AND_RESIZE`。
- 空图提示只在单根节点且无候选/生成时出现，且不拦截画布手势。

## 接口边界

- 未修改 `domain/MindMap`、`DocumentSession`、`Index`、存储、构建配置或 CONTRACT 中 DIYPage 的外部 Param/Event。
- `viewMode` 是 `MindMapCanvas` 的内部 `@Param`，由 `DIYPage` 的 `@Local canvasMode` 提供；不写入文档、备份或撤销历史。
- 3D 不改变领域命令、revision、候选校验和导出格式；导出仍由 `ExportService` 的完整 2D 布局生成。

## 状态

| 状态 | 表现 |
| --- | --- |
| 空白导图 | 画布顶部提示“从根节点开始”，根节点居中 |
| 选中 | 单节点强描边 + 整条分支高亮 |
| 折叠 | 徽标显示 `+N`，子树隐藏，`childCount` 保留 |
| 3D 视角 | 单指拖动按轨迹球自由旋转，无俯仰上限；复位恢复默认朝向并适应画布 |
| 生成中 | 顶部状态条显示进度、范围和取消；对话面板底部同步显示 |
| 候选 | 顶部预览条显示范围、节点数、摘要、确认/放弃；候选期间禁止编辑和导出 |
| 候选过期 | 标题改为“候选已过期”，确认禁用，提示放弃后重新生成 |
| 错误 | 错误文字使用 `fs_danger`，不覆盖当前导图 |
| 深色 | 同一语义色板；根节点浅紫底 + 深色文字，连线/点阵同步降亮 |
