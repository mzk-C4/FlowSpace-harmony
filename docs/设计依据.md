# 设计依据与来源

- [HarmonyOS skills](https://github.com/xiaowu5255/harmonyos-skills)：读取 ArkTS 语法、ArkUI 模式与存储相关 skill；采用显式类型、ArkUI V2 单向数据、官方 SDK 签名和 Repository 分层。依赖本机 API 24 构建验证，不把普通 TypeScript 语法通过当作 ArkTS 编译通过。
- [Emil design engineering](https://github.com/emilkowalski/skills/blob/main/skills/emil-design-eng/SKILL.md)：用于触控目标、文字对比、短促浮层反馈、输入状态、减少动效和布局稳定性。原生频繁节点操作即时响应，不加入排队过渡。暖白、石墨、单一蓝紫强调色；颜色资源分别定义浅色与深色。
- 本地 MathMate：只参考持续对话、流式通信与版本保护思路；未复制数学业务、Flutter 页面、拍照功能、模型配置或密钥。
- [ohos_mind_elixir](https://gitcode.com/CPF-ApplicationTPC/ohos_mind_elixir/tree/master)：验证的候选为1.0.1。源码审核与原生 Canvas 选择记录见 [DIY记录](implementation/diy-result.md)；独立 API24 验证见 [构建记录](implementation/native-library-proof.md)。当前应用使用自研 ArkUI Canvas，没有打包该库或复制其实现。

第三方 skill 文件仅在本地用于遵循指引，不作为产品代码分发。视频与资料的出处、许可和核验日期分别见 [视频](implementation/videos.md) 与 [资料](implementation/resources.md)。页面只收录自行撰写的介绍及链接，不复制教材或视频正文。
