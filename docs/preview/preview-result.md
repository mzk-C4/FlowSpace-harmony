## 浏览器自动验收限制

`mcp__cua_repl.js` 首先报告 `iab` 浏览器不可用。随后通过已发现的 Edge 浏览器调用 `cua.createBrowserTab` 打开本地 `file:` 入口时，被浏览器 URL 安全策略拒绝：`The requested URL protocol is not allowed. Allowed protocols: "http:", "https:"`，并明确禁止通过其他入口、浏览器或间接执行绕过。

因此停止该路径，没有改用本地 HTTP 等方式规避，也没有生成或声称存在浏览器验收截图。请人工双击本 HTML 完成以下检查：

1. 首页输入主题 → 预览生成效果 → DIY 可见分支，并能看到“演示”说明。
2. 新增/编辑/删除节点 → 撤销/重做 → 拖动/缩放 → 切换布局 → 折叠/展开。
3. 对话输入 → 候选显示 → 放弃图不变 → 重新输入并应用 → 撤销恢复。
4. 资料分类/搜索 → 详情 → 原站链接；“用这个主题”返回首页只填入简介。
5. JSON 导出后恢复为新文档，Markdown 与完整 PNG 下载；个人页改名、搜索、删除确认、外观与减少动效；刷新检查本地保存。
