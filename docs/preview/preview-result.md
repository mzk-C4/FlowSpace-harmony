# 四页面离线交互预览交付

2026 年 11 月 19 日的本地网页预览采用与鸿蒙手机端一致的苹果风格。

入口：本目录 `index.html`，可直接用现代浏览器打开。不需要联网加载脚本、字体或图片，不需要构建。原站资源链接与手动点击的后端检测需要网络；没有自动网络请求。

## 2026-11-26 自由摆放更新

- DIY 画布支持自由拖动节点：2D 整条分支刚性跟随，3D 子节点轻微弹性跟随；节点 1:1 跟手，松手立即停住（不再有惯性滑行），只做碰撞分离。首次拖动进入 `placement: 'free'`，位置写入 `positions` 并作为一个撤销单元提交。
- 长按节点打开菜单：加子节点、加同级、编辑、改父级、折叠、删除；根节点不提供同级/改父级/删除。自由模式下新增节点自动放在父节点右侧空位，删除会清理坐标。
- 「更多 → 整理为树形布局」清空坐标并恢复自动布局，可撤销。自由模式连线按父子相对位置选择贝塞尔连接边。
- 2D 与 3D 共用同一套图形语言：红/绿/琥珀彩色圆形节点、分支配色、连线关系小字、虚线跨分支关系，画布跟随浅/深色主题（浅色即录屏里的白底效果，深色为对应深色纸张）。3D 另有根节点居中、屏外景深虚化层、轨迹球旋转与透视缩放；`Shift`+拖动或右键拖动平移。自由坐标按层级深度投影，3D 中拖动节点通过逆投影更新 x/y，子节点弹性跟随并在松手后回到原相对位置。切回 2D 位置保留，3D 视角不写入文档。
- 2D 不再使用圆角卡片，改为与 3D 相同的圆形节点、关系标签和颜色体系；节点文字最多显示 4 个字符加省略号，完整文字在标题和编辑面板中查看。
- 文档新增可选 `links: [{from,to,label}]` 关系链接（多父/跨分支关系）：3D 以虚线加标签绘制；“更多 → 添加关系示例（3D）”会添加三条演示关系，和普通编辑一样可撤销。链接随 JSON 备份保存，后端放行、剥离后还原。
- JSON 备份与导入保留 `placement` / `positions` / `links`；无坐标的旧文档仍按自动布局打开。PNG 全图导出使用自由坐标并包含折叠分支。
- 后端只放行并保留位置与关系字段：发给模型前剥离，返回后按仍存在的节点还原；不改变 AI 生成/修改结构的行为。
- 拖动跟手实测（无头 Edge，指针位移 60×30px）：2D 与 3D 节点均移动 60×30px，旋转 3D 视角或缩放后仍为 1:1；松手后漂移 ≤0.5px。修复前 2D 松手多滑约 20px、3D 只跟到约 94%，现已移除惯性并改用精确逆投影。
- 3D 相机在拖动期间保持稳定，不再按新内容重新居中/缩放；拖根节点或大距离拖动后不会回弹（实测松手偏移 ≤0.3px）。
- 验证：`node --test docs/preview/test-preview.mjs` 46 项通过；`backend/tests/gateway.test.mjs` 13 项通过；`npm test` 160 项、`npm run check` 通过。
- 无头 Edge 实测：2D 拖动、长按菜单、重载持久化；3D 白底图、30 个景深节点、关系示例、轨迹球旋转、弹性拖动、切回 2D，页面无运行时错误。截图在 `artifacts/free-canvas/graph-*.png`（Git 忽略）。

## 浏览器自动验收限制

`mcp__cua_repl.js` 首先报告 `iab` 浏览器不可用。随后通过已发现的 Edge 浏览器调用 `cua.createBrowserTab` 打开本地 `file:` 入口时，被浏览器 URL 安全策略拒绝：`The requested URL protocol is not allowed. Allowed protocols: "http:", "https:"`，并明确禁止通过其他入口、浏览器或间接执行绕过。

因此停止该路径，没有改用本地 HTTP 等方式规避，也没有生成或声称存在浏览器验收截图。请人工双击本 HTML 完成以下检查：

1. 首页输入主题 → 预览生成效果 → DIY 可见分支，并能看到“演示”说明。
2. 新增/编辑/删除节点 → 撤销/重做 → 拖动/缩放 → 切换布局 → 折叠/展开。
3. 对话输入 → 候选显示 → 放弃图不变 → 重新输入并应用 → 撤销恢复。
4. 资料分类/搜索 → 详情 → 原站链接；“用这个主题”返回首页只填入简介。
5. JSON 导出后恢复为新文档，Markdown 与完整 PNG 下载；个人页改名、搜索、删除确认、外观与减少动效；刷新检查本地保存。

原生 ArkUI 的独立截图和编译验收见[架构与验收](../架构与验收.md)。
