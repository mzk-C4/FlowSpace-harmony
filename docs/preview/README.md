# 本地试用

用现代浏览器打开本目录 `index.html`，无需安装依赖、启动服务器或联网加载界面。

1. 首页点“打开示例导图 · 信号与系统”，进入与鸿蒙应用相同的 10 节点示例。再次点击打开已编辑的最新版，不重复创建；删除后仅在再次点击此按钮时恢复。浏览器内原有导图继续保留。
2. 选中节点后点“编辑”，或使用“＋ 节点”；同级、折叠、布局、新建与删除位于“更多”菜单。拖动画布平移，用下方按钮缩放和适应。
3. **拖动节点**可自由摆放，节点 1:1 跟手；松手立即停住，不再惯性滑行，只做碰撞分离，节点不会重叠。第一次拖动会切换到自由摆放模式；长按节点可打开“加子节点 / 加同级 / 编辑 / 改父级 / 折叠 / 删除”菜单。“更多 → 整理为树形布局”可清空自由坐标并恢复自动布局，同样可撤销。
4. **2D 与 3D 共用同一套图形语言**：彩色圆形节点、分支配色、连线关系小字和同一套浅/深色画布。右下角切换 2D / 3D；3D 额外有根节点居中的透视、球形轨迹球和淡出的背景景深节点。3D 中空白处拖动旋转、`Shift`+拖动（或右键拖动）平移、滚轮或按钮缩放、点“复位”回默认朝向；拖动节点时节点本身精确跟手，子节点轻微弹性跟随并回到原相对位置，松手立即停住。切回 2D 后位置保留。想要视频里的白底效果，把「个人 → 外观」切到浅色。
5. “更多 ···”里的 **添加关系示例（3D）** 会添加几条跨分支关系（虚线 + 标签），用来查看多关系网络的效果；它和普通编辑一样写入文档并可撤销。文档里的 `links` 会随 JSON 备份保存。
6. 自由坐标和关系链接保存在文档里：JSON 备份、PNG 导出和导入都会保留；旧备份没有坐标时仍按自动布局打开。
7. “继续整理”为离线规则演示：输入内容后先出现候选，点应用才添加节点，可撤销。它不调用真实 AI，也不调整节点位置或关系。
8. 点“导出”保存 JSON、Markdown 或完整 PNG。个人页可搜索、改名、删除或导入备份；规范 JSON 可与鸿蒙应用交换。
9. 资料库和工科视频在原站打开。联网查看原站不会把资料全文自动导入导图。

Ctrl/Cmd+Enter 创建演示导图或发送修改；在画布界面 Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Shift+Z 重做。编辑文本时保留浏览器原生撤销，中文输入法确认不会误发送。按钮与节点可使用 Tab、Enter/空格操作，弹窗支持 Escape。

个人页可切换浅色/深色/跟随系统及减少动效。文档仅保存在当前浏览器，清理浏览器数据前请导出 JSON 备份；不同浏览器不自动共享。

回归：`node --test docs/preview/test-preview.mjs`（在仓库根目录执行）。这是实际脚本逻辑测试，不代替浏览器和真机视觉验收。完整记录见本目录 `preview-result.md`。
