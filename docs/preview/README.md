# 网页工作区

启动 AI 网关后，在浏览器打开它的根地址。供应商模式默认是 [127.0.0.1:8787](http://127.0.0.1:8787/)，本机模型模式是 [127.0.0.1:18797](http://127.0.0.1:18797/)。[启动方法](../../README.md)

1. 输入主题或粘贴长文，最多 20,000 字符。提交后可以取消。收到完整导图才进入编辑器并保存。失败或取消时，输入可用于重试。
2. 点选节点后打开「继续整理」，指令作用于选中分支。可用「改为整图」切换范围。候选先画在画布上，点「确认应用」才保存，可整体撤销。生成期间手工改图会让原候选过期。
3. 选中节点后点「编辑」或「＋ 节点」。同级、折叠、布局、新建与删除位于「更多」菜单。拖动画布平移，用下方按钮缩放和适应。
4. 点「导出」保存 JSON、Markdown 或完整 PNG。个人页可搜索、改名、删除或导入备份，JSON 可与鸿蒙应用交换。

Ctrl/Cmd+Enter 可提交生成或发送修改。在画布上使用 Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Shift+Z 重做。文本框保留浏览器原生撤销，中文输入法确认时可继续输入。按钮与节点支持 Tab、Enter 或空格，弹窗支持 Escape。

直接打开 `index.html` 可以使用内置《信号与系统》示例、手工编辑和备份。文件页和网关网页的浏览器存储不同，已有导图可导出 JSON 并恢复到新入口。

在仓库根目录运行 `node --test docs/preview/test-preview.mjs`，检查生成、取消、版本保护、编辑和备份。
