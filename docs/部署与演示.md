# 部署、安装与课程演示

## 开发环境

- Node.js 24+：根目录 `npm run check`、`npm test`；零第三方npm依赖。Windows构建需要PowerShell 7（pwsh）。
- HarmonyOS 命令行工具及 SDK：本机 `E:/harmony system/command-line-tools`；产品 target/compatible 均为 `6.1.1(24)`。
- JDK 17：本机 `D:/projects/tools/jdk17/jdk-17.0.19+10`。其他电脑可传入自己的路径。
- 原项目含未提交改动，因此本次使用独立 `FlowSpace-mindmap` worktree。旧版快照为 `archive/workbench-20261103`。

## 配置真实模型

1. 根目录复制 `backend/.env.example` 为 `backend/.env`。
2. 本地填写 `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`。接口需要支持Chat Completions、流式SSE、temperature及max_tokens字段；完整协议见后端README。
3. 桌面调试默认 `HOST=127.0.0.1`；同一可信局域网手机联调设 `HOST=0.0.0.0`。运行 `npm start`。
4. 手机个人页保存电脑的可达地址和端口；点击连接检测。显示“已配置”仍不代表模型已调用成功。
5. 在首页生成一张小图，检查后端无错误、手机出现完整候选/正式导图，保存供应商模型名、测试日期、截图与错误记录；不要记录密钥或敏感正文。

该网关面向本机/可信局域网课程联调，不提供公网用户鉴权。若后续部署公网，需要在HTTPS鉴权网关后接入；本次未创建外部服务器、未改MathMate配置。

## 构建与签名安装

```powershell
npm run build:harmony
# 或显式指定工具
./tools/build-harmony.ps1 -Toolchain 'E:/harmony system/command-line-tools' -JavaHome 'D:/projects/tools/jdk17/jdk-17.0.19+10'
```

脚本将当前源码复制到英文临时目录并执行 `assembleHap --no-daemon`，输出目录 `artifacts/` 被Git忽略。当前产物是unsigned HAP，不能冒充已签名安装包。

在安装了API24 SDK的DevEco Studio中打开工程，为真实手机配置调试签名（开发者账户、证书与设备授权均由本机持有）；选择手机后运行。若DevEco无法处理中文路径，可以打开构建日志打印的英文临时工程再配置签名。不要把证书、profile或私钥提交到仓库。通过 `hdc list targets` 验证设备连接后，使用DevEco安装，或对已签名HAP执行 `hdc install <signed.hap>`。

## 三条演示

### 1. 首次生成

首页输入“整理信号与系统的核心知识，按时域、频域、系统性质和应用组织” → 点击生成 → 显示进度 → 完整导图出现并自动保存。编辑一个中文节点、增加子节点，打开源文检查原始输入。再粘贴一段20,000字以内长文重复；未配置时应明确报错，不展示伪造AI结果。

### 2. 对话修改、冲突与撤销

选择一个非根分支 → 打开继续整理 → 确认范围为“选中分支” → 输入“补充三个工程应用” → 画布显示候选 → 确认应用 → 撤销一次恢复原分支。将范围改成整张导图，再做结构重组。请求期间手动编辑节点，旧候选必须提示过期并拒绝覆盖；取消请求后输入、对话与已有图仍在。

### 3. 本地恢复与导出

手动增加/移动/折叠节点 → 等待“已保存” → 退出并重新启动 → 检查图、原文和对话 → 导出Markdown、JSON和PNG → 确认PNG含当前视口之外及折叠分支的节点 → 从个人页导入JSON形成新文档，原文档仍在。检查搜索、改名、删除确认及首页最近列表同步。
