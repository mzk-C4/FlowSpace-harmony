# 架构与验收记录

## 产品与实现

四个主页面为首页、DIY思维导图、资料库、个人。旧工作台路由、MockService、练习/任务/复习/排期组件和旧测试已从新工程移除；旧版仍可通过Git快照追溯。公共入口使用Navigation承载四个Tabs，页面使用ArkUI V2及事件回调。

```text
Home / DIY / Library / Profile
          │ 事件与不可变文档快照
          ▼
Index（请求、保存状态与候选编排）
   ├─ DocumentSession ── DocumentRepository ── RelationalStore
   │      └─ 命令、revision、撤销/重做          Preferences
   ├─ MindMapCanvas + MapLayout（只读绘制、选择、视口）
   ├─ ExportService（全图PNG / Markdown / JSON）
   └─ GenerationClient ── SSE ── Node网关 ── 兼容模型
```

领域模型独立于画布。稳定ID、唯一根、父节点、无环、无孤儿、8层与500节点由统一校验约束。所有图编辑和AI确认经过DocumentSession，revision递增，撤销/重做也递增；AI结果绑定requestId/documentId/baseRevision。初次结果只有在版本仍为0且未被修改时自动应用，其余先预览。失败创建保留已有导图并将源文/对话保存为可重试草稿；同一输入连续重试复用文档ID。手工改动后的草稿重试也必须确认候选。

Repository在新mindmaps.db内以事务保存当前文档与上次有效快照，串行处理写入；不迁移旧工作台数据。读取损坏文档时校验并回退快照，避免损坏稿污染好快照。打开、新建、导入和改名/删除前等待当前成功保存，防止异步失败后丢失内存编辑。保存失败明确保留未保存状态。设置保存成功后才更新当前偏好。系统自动备份关闭；用户通过JSON主动备份/恢复。

客户端本地保留完整对话（上限1000条），传输上下文最多20条、24,000字符；未完成JSON不会进入画布。网关独立、无文档长期存储；模型密钥只由服务端环境读取。对话修改校验选中子树外不变，结构格式错误只修复一次；取消/超时中断上游；同文档请求互斥，短期requestId回放避免重复生成。

PNG使用独立离屏完整树布局，包含折叠分支，最长边4096像素；当前缩放和可见区不影响结果。JSON携带schemaVersion并使用封装标识；校验后分配新documentId导入，不覆盖原文档。

## 画布选择

主应用使用自研ArkUI Canvas；没有WebView。第三方 `@ohos/mind-elixir@1.0.1` 已在独立最小页面以API24编译打包成功，不能将其描述为“API24不支持”。其V1状态、可变模型与自身撤销历史需要额外协调；本版先将正式数据和撤销统一在领域层，通过原生Canvas避免双份可写状态。详细事实与尚未验证的部分见[原生库验证](implementation/native-library-proof.md)。两种实现的中文输入、触控缩放和设备数据恢复仍需手机检查；当前选择属于架构隔离决策，不是对第三方库运行失败的断言。
