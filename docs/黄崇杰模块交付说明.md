## 2. 页面布局、主要交互与返回路径

### 11 安排总览

入口：首页「安排总览」。

布局自上而下：

1. 汇总卡：日期与星期、计划版本、今日学习分钟、生活保留分钟、每日上限；超限时给出提示。
2. 快捷入口：复习清单、知识关联项目。
3. 七日日期条：显示每天任务数量，可切换查看。
4. 各空间安排卡：本周任务数、本周分钟数、今日任务数、下一条任务；点击进入该空间的七日时间轴。
5. 当日生活保留时间：早餐、午饭与午休、晚饭、洗漱休息，以及固定课程/家庭时间。
6. 当日任务列表（所有空间）：点击进入任务详情。

返回：使用 NavDestination 默认返回，回到首页；返回时首页重新读取今日任务，保证状态同步。

### 12 空间学习时间轴

入口：安排总览的空间卡；路由参数为 `spaceId`，缺省为 `space_ds`。

布局：

1. 空间头部：名称、目标、计划版本、本周任务数/学习时长/每日上限。
2. 七日横向日期条：显示星期、日期、任务数，今天带标记。
3. 当日摘要：学习分钟、保留分钟；超过每日上限时提示。
4. 生活保留时间：明确标注「不可占用」。
5. 学习任务卡：时间段、时长、标题、预计产出、清单进度、状态标签，以及「开始/继续」「调整」「任务详情」入口。
6. 可撤销卡：仅在存在本空间调整快照时出现，撤销前需要二次确认。

返回：默认返回安排总览；从任务详情或调整预览返回时，页面通过 `onShown` 重新取数，任务状态和拆分结果立即刷新。

### 13 学习任务详情

入口：时间轴任务卡、安排总览当日任务、首页今日任务、复习清单中已排期的任务。

布局：

1. 头部：所属空间、任务状态、任务名称、日期/星期、时间、时长。
2. 预计产出。
3. 任务清单：完成数/总数、进度条、逐项勾选与单项分钟数。
4. 关联知识：知识点标签，点击进入「知识关联项目」，并按当前空间过滤。
5. 操作区：
   - 待开始：开始任务；
   - 进行中：标记完成；
   - 已完成：禁用完成按钮；
   - 未完成且为今天、时长不少于 45 分钟时，可进入「调整计划」。其他情况显示原因提示。

返回：默认返回来源页；从知识关联项目返回时通过 `onShown` 刷新。开始/完成/勾选后立即重新读取任务。

### 14 计划调整预览

入口：任务详情或时间轴的「调整」；路由参数为 `taskId`。

布局：

1. 预览头部：调整原因、任务名、目标日期切换（周四 10-22 / 周五 10-23）、「取消不改动」说明。
2. 每日时长对比：今天与目标日调整前后的分钟数、是否在上限内、总量守恒说明。
3. 调整内容：拆分项与新增项的时间、分钟数、说明；含「提交前检查」时额外显示 5 + 5 分钟拆分。
4. 冲突检查：无冲突显示通过和生活时间/任务避让说明；有冲突逐条列出，并禁用「确认调整」。
5. 底部：「取消，不改动」与「确认调整」。

行为约定：

- 打开预览、切换目标日期只重新生成预览，不修改任务。
- 取消直接返回，不写入任何正式计划。
- 确认前再次校验预览版本、任务时间与时长、冲突列表；通过后修改原任务并新增续接任务，计划版本 +1。
- 确认成功后返回来源页，时间轴/总览/首页重新取数。

默认演示数据：`task_101` 为今天 19:00-19:45 的 45 分钟任务。

- 选择周四：今天 19:00-19:15（15 分钟）+ 周四 19:00-19:30（30 分钟），总量 45 分钟不变。
- 选择周五：19:00 与固定课程 19:00-20:30 冲突，确认按钮禁用。

返回：取消、默认返回均回到来源页；确认后 `pop()` 回来源页。

### 17 复习清单

入口：安排总览快捷入口。

布局：

1. 头部：待复习/已排期/已复习数量，明确「加入清单不等于自动排期」。
2. 主动加入面板：从练习记录候选中选择「加入清单」；来源保留 `nodeId`、`recordId`。
3. 立即复习面板：展示题目与笔记，填写自我检查后可提交；只记录完成，不生成日历任务。
4. 安排时间面板：四个候选时间段；确认时校验跨空间任务、生活保留时间和每日上限。
5. 分组列表：待复习、已排期、已复习；已排期项可进入生成的复习任务。

候选时间段与预期结果（初始数据）：

| 时间段 | 预期 |
|---|---|
| 今天 21:30-21:45 | 今天已有 115 分钟，再加 15 分钟超过 120 分钟上限，拒绝 |
| 明天 19:00-19:15 | 与 `task_104` 19:00-19:45 重叠，拒绝 |
| 周四 21:00-21:15 | 无冲突，生成 15 分钟复习任务 |
| 周五 19:00-19:15 | 与固定课程 19:00-20:30 冲突，拒绝 |

返回：默认返回安排总览；从生成的复习任务返回时刷新复习状态。

### 19 知识关联项目

入口：安排总览快捷入口；任务详情「关联知识」/知识点标签（带 `spaceId` 过滤）。

布局：

1. 说明卡：解释「知识 → 项目功能」的展示目的，区分原始资料、样例补充和个人练习。
2. 空间筛选条：全部 + 当前有关联的空间。
3. 关联卡：知识点 → 功能名、所属空间、功能说明；点击展开实现说明、原始资料（标题/正文/来源）与关联练习。

返回：默认返回来源页；从任务详情进入时保留空间筛选。

## 3. 空态与错误态

| 场景 | 表现 |
|---|---|
| 总览/时间轴/列表加载中 | 居中「加载中...」 |
| `spaceId` 不存在 | 「空间不存在或已过期」，可返回安排总览 |
| `taskId` 不存在 | 「任务不存在或已过期」，可返回 |
| 某天没有任务 | 「这一天没有学习任务 / 这一天没有任务」 |
| 空间筛选后无项目关联 | 「没有关联项目」，可切换回全部 |
| 没有可加入的练习记录 | 「暂无可加入的练习记录」 |
| 复习清单为空 | 分组为空，页面仍保留主动加入入口 |
| 调整预览冲突 | 橙色冲突卡逐条说明，确认按钮禁用 |
| 调整预览过期/任务被修改 | 返回错误文案，要求重新预览 |
| 撤销条件不满足 | 提示已有后续调整、任务进展或撤销后冲突 |
| 每日时长超限 | 总览、时间轴、预览、复习排期均给出具体分钟数 |
| 排期时间重叠/占用生活时间 | 返回具体任务、保留时间或课程名称 |

## 5. Service 接口

所有接口均为异步，页面不维护任务副本，写操作后重新调用读取接口。

| 接口 | 说明 |
|---|---|
| `getScheduleOverview(): Promise<ScheduleOverview>` | 汇总七日、各空间统计、今日学习/保留分钟、计划版本 |
| `getSpaceTimeline(spaceId: string): Promise<SpaceTimeline>` | 单个空间七日计划、生活保留、版本、可撤销标记 |
| `getTaskDetail(taskId: string): Promise<LearningTask \| null>` | 返回任务深拷贝，供详情页 @State 刷新 |
| `startTask(taskId: string): Promise<ActionResult>` | 待开始 → 进行中 |
| `completeTask(taskId: string): Promise<ActionResult>` | 标记完成并勾选全部清单 |
| `toggleChecklistItem(taskId: string, itemId: string): Promise<boolean>` | 切换单项清单 |
| `createAdjustPreview(taskId: string, targetDate: string): Promise<PlanAdjustPreview \| null>` | 生成预览，只读正式计划；含冲突、时长、总量说明 |
| `confirmAdjust(previewId: string): Promise<ActionResult>` | 校验版本与冲突后写入；拆分任务、保存快照 |
| `undoLastAdjust(spaceId: string): Promise<ActionResult>` | 检查后续调整、任务状态、清单勾选、拆分任务进展及撤销后冲突 |
| `getActiveSnapshot(spaceId: string): Promise<PlanSnapshot \| null>` | 查询本空间可撤销快照 |
| `getReviewItems(): Promise<ReviewItem[]>` | 复习清单（返回新数组） |
| `getReviewCandidates(): Promise<ReviewCandidate[]>` | 可加入的练习记录（返回新数组） |
| `addReviewFromCandidate(candidateId: string): Promise<ActionResult>` | 主动加入；只进入待复习，不生成任务 |
| `completeReview(reviewId: string): Promise<ActionResult>` | 立即复习/完成；若已排期则同步完成对应任务 |
| `scheduleReview(reviewId, date, timeRange, durationMinutes): Promise<ActionResult>` | 用户确认时间后才生成有时间的任务；校验冲突与上限 |
| `getProjectLinks(spaceId: string): Promise<ProjectLink[]>` | 知识 → 项目功能关联；空字符串返回全部 |

复用接口：`getTodayTasks`、`getRecentSpace`、`getSpacesFiltered` 继续作为首页数据源；`getTodayTasks` 直接读取 `PLAN_TASKS`，因此调整、撤销、开始/完成后首页同步。

## 6. 跨页联动约定

- 首页、安排总览、时间轴、任务详情共享 `PLAN_TASKS`，不各自复制任务数据。
- 任务状态变化后：来源页 `onShown` 或 pop 回调重新取数。
- 调整确认：原任务时长/时间段/清单改变，目标日新增续接任务，计划版本 +1，所有视图同步。
- 调整取消：只 pop，不写任务、不写版本。
- 撤销：仅时间轴提供，需要二次确认；撤销后恢复原时间段、时长、产出、清单，删除续接任务，版本 +1。
- 复习：加入清单、立即复习都不生成日历任务；只有用户选定时间段并确认后才新增任务。
- 知识关联：按 `spaceId` 可选过滤，从任务详情进入时自动带当前空间。

## 7. 手工验收步骤

1. 首页 → 安排总览：确认今日学习 115 分钟、保留时间与各空间汇总；切换日期，任务列表随之变化。
2. 进入「数据结构与算法」时间轴：确认七日安排、今天 4 条任务、生活保留时间；开始 `task_102`，返回首页确认状态变化。
3. 打开 `task_101` 详情：确认时间、清单 2/5、产出、关联知识；勾选一项，进度变化。
4. 点击「调整计划」，选择周五：确认课程冲突提示且「确认调整」不可用；取消返回，确认任务仍为 45 分钟。
5. 再次进入，选择周四：确认今天 15 分钟 + 周四 30 分钟、总量 45 分钟；确认后：
   - 今天任务变为 19:00-19:15；
   - 周四出现 19:00-19:30 的续接任务；
   - 总览/首页今日分钟数下降 30。
6. 回到时间轴：撤销卡出现；先取消一次确认无变化，再确认撤销，恢复 45 分钟并删除续接任务。
7. 复习清单：加入第 4 条练习记录；立即复习一条；依次尝试四个时间段，确认只有周四 21:00-21:15 成功，其余给出明确原因。
8. 知识关联项目：从总览查看全部；从任务详情进入时只显示当前空间；展开卡片查看实现说明、原始资料与练习。
9. 返回路径：每一页使用系统返回均能回到来源页；返回后数据刷新。
